# Радар БПЛА — версия для хостинга

Бот читает публичный канал-источник, обновляет карту угроз и присылает её в ваш канал.
Дополнительно перепубликует суточные сводки «сбито N БПЛА» текстовой табличкой.

## Что нужно задать

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `CHAT_ID` | ваш канал: `@username` или `-100…` (бот — админ с правом постинга) |
| `SOURCE_CHANNEL` | по умолчанию `radarrussiia` |
| `POLL_SECONDS` | период опроса, по умолчанию 12 |
| `TTL_MINUTES` | снятие «зависшей» угрозы, по умолчанию 180 |

`.env` в архив не входит — секреты задаются только в панели хостинга.

## Запуск (Amvera)

### 1. Подготовка

```powershell
# Упаковать проект в архив (PowerShell):
.\package.ps1
# Результат: dist/radar-bot-hosting_1.0.zip
```

### 2. Создание проекта на Amvera

1. Создать проект → тип **«Приложение»** → окружение **Python 3.12**
2. Загрузить архив `radar-bot-hosting_*.zip`
3. В **«Переменные окружения»** добавить:
   - `BOT_TOKEN` — токен от @BotFather
   - `CHAT_ID` — ваш канал (`@username` или `-100xxxxxxxxxx`)
4. **Постоянное хранилище**: `/data` (уже настроено в `amvera.yaml`)
   - там сохраняются: `state.json`, `map.png`, `bot.log`
   - данные переживают перезапуск контейнера
5. Нажать **«Развернуть»** (Deploy)

### 3. Первый запуск

Бот автоматически:
- Загрузит последние посты из канала-источника
- Восстановит актуальную картину угроз
- Отправит стартовую карту в ваш канал

### Локальная проверка

```bash
python bot.py --check   # проверка токена и подключения к Telegram
python bot.py --once    # один проход без цикла (для тестирования)
```

Лог: `/data/bot.log` (на сервере) или `logs/bot.log` (локально).
Строка успеха: `база формулировок: v2, маркеров: N`.

## Что важно знать

- **Сеть**: нужен доступ к `t.me` (источник) и `api.telegram.org` (отправка).
  Если хостинг блокирует Telegram — бот не сможет публиковать.
- **Данные**: `data/regions.geojson` (геометрия), `data/lexicon.json` (формулировки).
  Lexicon можно править без перезапуска бота.
- **TTL**: угроза автоматически снимается через 180 мин (настраивается) без подтверждения.
- Карта — не официальное предупреждение; первоисточник — канал-источник.
